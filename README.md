# Confessions

README files can be tiring to write, but sometimes, they are worth it.

Here's something different.

A little reminder to take care of your mind. Stay safe. No, seriously. Be safe.

### Here's how:

```bash
mkdir confessions
cd confessions
nano diary.md
# or
vim diary.md
```

Open the file. Write it all down. The thoughts, the feelings, the things you cannot quite say out loud.

Journal yourself into being okay.

You got this.

**Take care of yourself.**
